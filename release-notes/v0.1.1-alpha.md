# PrivateAIMail 0.1.1-alpha

## Fixed

- **Gmail OAuth login** now works against a real Google Cloud OAuth client.
  v0.1.0-alpha shipped with a placeholder `client_id` and would surface
  *"Error 401: invalid_client — The OAuth client was not found"* on the
  Google sign-in page. Connecting a Gmail account from
  Settings → Accounts → Add Gmail now completes successfully.
- Bundle now registers the reversed-client-ID custom URL scheme so the
  authorization callback reaches the app correctly.

## How updates land

If you installed v0.1.0-alpha already, Sparkle will offer this update
automatically the next time you launch the app, or right now via
**PrivateAIMail → Check for Updates…**. The model and any sync state
you've already pulled remain intact across the update.

If you're installing fresh — see the install steps below.

## What's included (carried from 0.1.0-alpha)

- Gmail account connection via OAuth 2.0 (Google verification screen
  will say "Google hasn't verified this app" — click Advanced → Go to
  Private AI Mail (unsafe). Standard behaviour for unverified OAuth
  clients in alpha)
- Thread list with on-device AI briefs (Gemma 4 E2B, ~3.6 GB first-launch
  download)
- Reply composer with real Gmail send
- Automatic updates via Sparkle 2

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account whose email is listed under **Test users** of the
  app's OAuth consent screen (project `mediaplatform-210614`)

## Installation (fresh)

1. Download `PrivateAIMail-0.1.1-alpha.dmg`.
2. Mount the DMG and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper (one-time, this build is ad-hoc-signed):

   **Terminal:**
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
   then double-click as usual.

   **GUI:** double-click → click Done on the warning → System Settings →
   Privacy & Security → scroll to the blocked-app row → Open Anyway.
4. First launch downloads the Gemma 4 E2B model (~3.6 GB).

## Known limitations

- Single-window interface only
- No push notifications (polling-based sync)
- No attachment preview
- No Microsoft 365 / Outlook support yet
- Ad-hoc signed — see installation steps for the one-time Gatekeeper
  unblock
