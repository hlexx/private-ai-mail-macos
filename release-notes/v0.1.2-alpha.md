# PrivateAIMail 0.1.2-alpha

## Fixed

- **Gmail OAuth no longer crashes the app on the callback.** v0.1.1-alpha
  shipped with a Swift 6 actor-isolation bug: the
  `ASWebAuthenticationSession` completion handler was being inferred as
  `@MainActor` (because it was declared inside an `@MainActor` function),
  but the system invokes that callback from an XPC reply queue. The Swift 6
  runtime check `_swift_task_checkIsolatedSwift` would trip on closure
  entry and SIGTRAP the process — *before* we ever reached the OAuth code
  exchange. The completion is now an explicit `@Sendable` closure that
  captures the session through a Sendable box, so no `@MainActor` isolation
  is inferred and the runtime check passes regardless of which queue the
  callback arrives on.

## How updates land

If you installed v0.1.1-alpha already, Sparkle will offer this update
automatically the next time you launch the app, or right now via
**PrivateAIMail → Check for Updates…**. The model and any sync state
you've already pulled remain intact across the update.

If you're installing fresh — see the install steps below.

## What's included (carried from 0.1.1-alpha)

- Gmail OAuth login against a real Google Cloud OAuth client (iOS-type,
  reversed-client-id custom URL scheme registered in `Info.plist`)
- Thread list with on-device AI briefs (Gemma 4 E2B, ~3.6 GB first-launch
  download)
- Reply composer with real Gmail send
- Automatic updates via Sparkle 2

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account whose email is listed under **Test users** of the
  app's OAuth consent screen (project `mediaplatform-210614`)

## Installation (fresh)

1. Download `PrivateAIMail-0.1.2-alpha.dmg`.
2. Mount the DMG and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper (one-time, this build is ad-hoc-signed):

   **Terminal:**
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
   then double-click as usual.

   **GUI:** double-click → click Done on the warning → System Settings →
   Privacy & Security → scroll to the blocked-app row → Open Anyway.
4. First launch downloads the Gemma 4 E2B model (~3.6 GB).

## Known limitations

- Single-window interface only
- No push notifications (polling-based sync)
- No attachment preview
- No Microsoft 365 / Outlook support yet
- Ad-hoc signed — see installation steps for the one-time Gatekeeper
  unblock
