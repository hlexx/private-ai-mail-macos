# PrivateAIMail 0.1.9-alpha

## What's new

- **Email-client keyboard shortcuts.** Reply (`⌘R` / `R`), Reply All
  (`⌘⇧R` / `A`), Forward (`⌘⌥F` / `F`), Archive (`E`), Star (`S`),
  Trash (`#` / `⌘⌫`), and Mark Read/Unread (`⇧I` / `⇧U`) now match
  Apple Mail and Gmail conventions. Single-letter shortcuts only fire
  when no text field is focused — typing in the composer or search bar
  works as expected.

- **`⌘R` is now Reply (was Refresh).** Refresh moved to `F5` / `⌘⇧L`.

- **Thread navigation with `J`/`K`.** `J` moves to the older thread,
  `K` to newer — matching Gmail. At the end of the list, the cursor
  wraps with a subtle border pulse. `Space` pages down in the reading
  pane; at the bottom it advances to the next unread thread.

- **Folder jumps: `⌘1`–`⌘5`.** `⌘1` Inbox, `⌘2` Starred, `⌘3` Sent,
  `⌘4` Archive, `⌘5` All Accounts.

- **`⌘L` focuses search.** `Esc` clears the query, second `Esc` blurs.

- **`⌘⏎` sends** from both the full compose window and the inline
  composer.

- **`?` opens a keyboard-shortcut help overlay** listing every shortcut
  grouped by section (Mail, Navigation, Compose, View). Dismiss with
  `?`, `Esc`, or click outside.

- **Settings → Keyboard tab** shows the same reference list. Customisable
  shortcuts are planned for a future release.

- **Mail command menu.** A dedicated Mail menu in the menu bar organises
  all actions with their keyboard accelerators. Help → Keyboard Shortcuts
  (`⌘⇧?`) opens the overlay from the menu bar.

## How AI works in PrivateAIMail

- **Brief + Reply drafts:** Gemma 4 (on-device, via MLX). No network call.
- **Translation:** Apple's `Translation` framework (on-device, no network).
  Independent of the Gemma LLM — uses Apple's neural translation models.

These are two separate on-device AI systems. Neither sends your email data
off your Mac.

## How updates land

If you're on v0.1.8-alpha, **PrivateAIMail → Check for Updates…** installs
this update in place.

## Post-update notes

- `⌘R` no longer triggers sync — use `F5` or `⌘⇧L` instead.
- Press `?` at any time to see the full shortcut reference.
- Existing shortcuts (`⌘N` compose, `⌘K` action sheet, `Esc` dismiss)
  continue to work unchanged.

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account whose email is listed under **Test users** of the
  app's OAuth consent screen (project `mediaplatform-210614`)

## Installation (fresh)

1. Download `PrivateAIMail-0.1.9-alpha.dmg`.
2. Mount the DMG and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper (one-time, this build is ad-hoc-signed):
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
4. First launch downloads the Gemma 4 E2B model (~3.6 GB).

## Known limitations

- App Sandbox disabled for alpha (will return with Developer ID
  notarization)
- Snooze requires a background scheduler — Phase 2
- Log to CRM requires an integration (Notion/HubSpot/Salesforce) — Phase 2
- Per-node translation cache is in-memory only; restarts re-translate
- Ad-hoc signed — see installation steps for the one-time Gatekeeper
  unblock
- Customisable keyboard shortcuts planned for a future release
