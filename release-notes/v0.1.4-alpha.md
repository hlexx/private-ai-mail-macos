# PrivateAIMail 0.1.4-alpha

## Fixed

- **Gmail bootstrap sync no longer fails silently.** v0.1.3-alpha
  surfaced *"The operation couldn't be completed. (MailSync.SyncError
  error 0.)"* in Settings → Accounts after connecting a real Gmail —
  Swift's default `Error` bridging was hiding the actual cause. Both
  `SyncError` and `GmailAPIError` now conform to `LocalizedError` and
  pass the underlying error verbatim through to the UI.
- **OAuth scope conflict removed.** The previous default scope set
  requested both `gmail.readonly` and `gmail.metadata`. Google treats
  the metadata variant as mutually exclusive: combining the two yields
  a token with metadata-only access, so any message-body read returns
  `403 insufficient_scope` and Bootstrap aborts. Dropped
  `gmail.metadata` (it's a subset of `gmail.readonly`, which is what
  the on-device pipeline needs anyway).

## How updates land

If you installed **v0.1.3-alpha**, Sparkle's auto-update is now wired
correctly: **PrivateAIMail → Check for Updates…** should install this
release in place. (This is also the first end-to-end smoke test of the
Sparkle fix from 0.1.3.)

After the update, **remove the Gmail account and re-add it** so a
fresh access token without the conflicting `gmail.metadata` scope
gets issued. Re-using the old token would still hit the same 403.

If you're on **0.1.2-alpha or earlier**, do a manual DMG install
(those builds can't auto-update — Sparkle was broken until 0.1.3).

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account whose email is listed under **Test users** of the
  app's OAuth consent screen (project `mediaplatform-210614`)

## Installation (fresh)

1. Download `PrivateAIMail-0.1.4-alpha.dmg`.
2. Mount the DMG and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper (one-time, this build is ad-hoc-signed):

   **Terminal:**
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
   then double-click as usual.

   **GUI:** double-click → click Done on the warning → System Settings →
   Privacy & Security → scroll to the blocked-app row → Open Anyway.
4. First launch downloads the Gemma 4 E2B model (~3.6 GB).

## Known limitations

- Single-window interface only
- No push notifications (polling-based sync)
- No attachment preview
- No Microsoft 365 / Outlook support yet
- Ad-hoc signed — see installation steps for the one-time Gatekeeper
  unblock
- App Sandbox disabled for alpha; will be restored alongside
  Developer ID notarization
