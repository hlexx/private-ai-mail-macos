# PrivateAIMail 0.1.11-alpha

## New

- **Mixed-language email translation.** Translation now handles
  bilingual and multilingual emails. Each text node is independently
  language-detected; only chunks NOT in the preferred language are
  translated. English-dominant emails with a few Thai, Russian, or
  German fragments now show all non-preferred text translated while
  the preferred-language text stays unchanged.

- **Short-fragment safety.** Fragments of 3 characters or fewer and
  low-confidence detections (< 50%) are preserved as-is — no
  false-positive translations of "OK", "Hi", or ambiguous tokens.

- **Per-source-language caching.** Cache is keyed by source-language
  pair: switching preferred language re-translates only what's needed.
  Previously translated batches remain cached and are reused instantly.

- **Settings hint.** The preferred-language picker now explains that
  mixed-language emails translate only the non-preferred parts.

## What's included (carried from 0.1.10-alpha)

- Label reconciler (M010) for accurate Inbox/Archive state
- Email-client keyboard shortcuts (Apple Mail + Gmail conventions)
- `?` keyboard-shortcut help overlay + Settings → Keyboard tab
- Focus-aware single-letter shortcuts
- Persistent thread briefs, HTML rendering, real AI in composer,
  label-aware sync, mutations, translation, multi-language replies

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account in the OAuth Test users list

## Installation (fresh)

1. Download `PrivateAIMail-0.1.11-alpha.dmg`.
2. Mount, drag **PrivateAIMail** to `/Applications`.
3. ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
4. Launch. First-launch AI model download is ~3.6 GB.

## Known limitations

- Translation cache is in-memory only; cleared on app restart.
- CID images requiring `messages.attachments.get` download are still
  Phase 2.
- App Sandbox off for alpha; back on with Developer ID notarisation.
- Ad-hoc signed.
