# PrivateAIMail 0.1.6-alpha

## New features

- **Persistent AI briefs.** Thread briefs now persist in a local
  `thread_brief` table. Briefs survive app restarts and load instantly
  from the database instead of re-running the on-device model.
- **Background brief generation.** A throttled background queue
  automatically generates briefs for inbox threads after sync.
  Settings > AI shows real-time progress ("Background briefs: X / Y
  generated").
- **Working chip filters.** "Needs reply", "Has deadline", and
  "AI handled" chips in the top row now query the `thread_brief`
  table with real SQL predicates. Previously they returned empty
  results.
- **Folder counts respect account selection.** Selecting a single
  account in the sidebar now scopes Inbox / Starred / Sent / Archive
  counts to that account only. "All accounts" shows totals across
  all accounts.
- **Star button visual state.** The star icon in the thread header
  now reflects the actual STARRED label state. A starred thread shows
  a filled star; toggling updates the icon in real-time.
- **Inline CID image resolution.** Embedded images in HTML emails
  (e.g. logos via `<img src="cid:...">`) now render correctly instead
  of showing broken-image placeholders.
- **Undo toast timer fix.** The undo toast no longer leaves orphan
  timers when rapidly archiving and undoing. Each toast cancels the
  previous timer cleanly.

## Bug fixes

- Unified plain-text extraction through `MessageRecord.bestPlainText`
  across BriefStore, ReplyStore, and TranslationStore.
- Thread brief language detection stored in the database for
  consistent reply-language routing.

## How to test

1. First launch: Settings > AI shows background brief progress counter
   ticking up as Gemma processes the backlog.
2. After ~50 briefs: click "Needs reply" chip — threads with action
   requests appear. Click "Has deadline" — threads with deadlines.
   Click "AI handled" — all briefed threads.
3. Quit and reopen: open a previously briefed thread — loads instantly.
4. Star a thread: filled star icon appears. Unstar: contour star.
5. Open a marketing email with inline logo: image renders, not a
   broken placeholder.
6. Select an account in sidebar: folder counts match that account.
7. Archive > Undo > Archive > Undo rapidly: no stuck toasts.

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account listed under Test users of the app's OAuth
  consent screen

## Installation

1. Download `PrivateAIMail-0.1.6-alpha.dmg`.
2. Mount and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper:
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
4. First launch downloads the Gemma 4 E2B model (~3.6 GB) if not
   already cached from a previous version.

## Known limitations

- Single-window interface only
- No push notifications (polling-based sync)
- No Microsoft 365 / Outlook support yet
- "Logged" filter is a placeholder (CRM integration is Phase 2)
- Ad-hoc signed; see installation steps for the Gatekeeper unblock
- App Sandbox disabled for alpha
