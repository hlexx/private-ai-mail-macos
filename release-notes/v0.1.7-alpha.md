# PrivateAIMail 0.1.7-alpha

## Fixed

- **Inbox / All Accounts / Sent / Starred filters no longer empty after
  upgrade.** Threads synced before label-aware code landed (v0.1.4 and
  earlier) never got rows written to the `thread_label` table, and v0.1.6's
  label-driven SQL filters returned an empty set for the entire historical
  inbox — the user saw `Archive: 481 / Inbox: 0 / All Accounts: 0` after
  upgrading. New migration M008 backfills the `INBOX` system label for any
  thread with zero label rows (the assumption matches where the user used
  to see those threads). The next Gmail incremental sync overwrites the
  backfill with the real label set.

## How updates land

If you're on v0.1.6-alpha, **PrivateAIMail → Check for Updates…** installs
this fix in place. On first launch after update, the migration runs once
and your old threads reappear under Inbox / All Accounts immediately.

## What's included (carried from 0.1.6-alpha)

- Persistent AI brief storage in `thread_brief` (briefs survive restart)
- Background brief generation queue after every sync delta
- `Needs reply` / `Has deadline` / `AI handled` chip filters wired to
  real brief data
- Star button reflects current STARRED-label state visually
- Inline `<img src="cid:...">` resolution in HTML emails
- Folder counts scoped per selected account
- Undo-toast timer cancellation
- All v0.1.5 features (HTML rendering, real AI composer, label-aware
  sync, mutations, translation, multi-language replies, layout fixes)

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account whose email is listed under **Test users** of the
  app's OAuth consent screen (project `mediaplatform-210614`)

## Installation (fresh)

1. Download `PrivateAIMail-0.1.7-alpha.dmg`.
2. Mount the DMG and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper (one-time, this build is ad-hoc-signed):
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
4. First launch downloads the Gemma 4 E2B model (~3.6 GB).

## Known limitations
