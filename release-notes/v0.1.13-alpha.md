# Re:Box 0.1.13-alpha

## New

- **PromptTask registry.** Thread briefs, draft replies, and attachment
  summaries now share one typed task registry with explicit prompt versions,
  schema versions, context limits, parser contracts, examples, and cache
  metadata.

- **Attachment summary foundation.** Re:Box can fetch Gmail attachment bytes,
  store them locally, extract text from PDF and text-like files, chunk the
  extracted text, cache summary artifacts, and run attachment summaries through
  the same on-device AI path as other tasks.

- **Summarize wiring in the reading pane.** The existing Summarize action is
  connected to feature state and shows extracting, summarizing, cached,
  unsupported, and retryable failure states.

- **Re:Box app name.** The macOS display name, app menu, and Sparkle update
  feed now use Re:Box.

## Improved

- Draft replies use the shared structured-task executor, tolerant parsing, JSON
  completion stopping, and safer prompt trimming.
- AI eval reports now include task id and prompt version, plus attachment
  summary metrics for schema validity, evidence coverage, and hallucination
  rate.
- Attachment AI artifacts are versioned by task id, prompt version, schema
  version, model id, extraction version, and input fingerprint.

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account in the OAuth Test users list

## Known limitations

- Attachment summary v1 supports PDF text, `text/*`, HTML, JSON, and CSV.
- DOCX extraction and image OCR are follow-up work and remain unsupported.
- App Sandbox off for alpha; back on with Developer ID notarisation.
- Ad-hoc signed.
