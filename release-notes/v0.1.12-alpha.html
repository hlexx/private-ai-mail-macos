PrivateAIMail 0.1.12-alpha

New

  • Attachment intelligence in the reading pane. Messages now show real attachment cards with local-file, extraction, processing, summary, evidence, unsupported-format, and missing-local-bytes states.
  • Local attachment processing queue. Attachment extraction and summary work now runs through a bounded local queue with cancellation, selected-attachment priority, duplicate-work protection, and explicit persistence of job state.
  • Local file preview. Attachment preview opens the saved local file when it exists and reports a clear missing-file state when bytes have not been saved locally.
  • Manual privacy smoke test. Project notes now include a manual verification path for PDF, text, unsupported, missing-local-file, and no-attachment messages, including log and network checks.

Privacy and scope

  • Attachment content stays on device.
  • Extracted text, summaries, evidence chunks, and attachment bytes are not logged.
  • This release does not add Gmail remote attachment download.
  • This release does not add Team Connect, Slack, Notion, CRM, or cloud attachment processing.

Known limitations

  • Gmail attachment bytes must already be present locally; the app does not fetch missing attachment bytes from Gmail in this release.
  • Unsupported attachment formats are shown explicitly and are not summarized.
  • Team Connect actions remain out of scope for this release.
  • App Sandbox is off for alpha; re-enable with Developer ID notarisation.
  • Ad-hoc signed unless Developer ID release credentials are present locally.
