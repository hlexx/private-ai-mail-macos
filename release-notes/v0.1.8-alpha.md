# PrivateAIMail 0.1.8-alpha

## What's new

- **Translation preserves HTML layout.** The Translated tab now keeps the
  original email structure — images, tables, buttons, font sizes, colours —
  intact. Only the visible text is translated via a DOM walk inside the
  existing WKWebView. No more wall-of-plaintext or leaked CSS keywords like
  "Семейство шрифтов: Arial".

- **Inbox backfill catches more threads (M009).** Threads that had labels
  like UNREAD or CATEGORY_PROMOTIONS but were missing the INBOX label are
  now included in All Accounts and Inbox views. Previously only threads with
  zero labels were backfilled.

- **Draft Reply button works.** Click "Draft reply" in the Brief Rail (or
  press `⌘⇧R`) to scroll to the inline composer and generate an AI draft in
  the thread's language. Snooze and Log to CRM are explicitly disabled with
  tooltips explaining they ship in Phase 2.

- **Responsive 4-pane layout.** Sidebar and Brief Rail are now collapsible
  via toolbar toggle buttons. All splitters are draggable and positions
  persist across quits. Default widths prioritise the reading pane and AI
  brief — together they get ~64% of window width on a 1440px display.

- **AI brief no longer parrots CSS.** `<style>` and `<script>` blocks are
  stripped before plaintext extraction, so the AI brief reads about the
  actual email content, not font-family declarations.

## How AI works in PrivateAIMail

- **Brief + Reply drafts:** Gemma 4 (on-device, via MLX). No network call.
- **Translation:** Apple's `Translation` framework (on-device, no network).
  Independent of the Gemma LLM — uses Apple's neural translation models.

These are two separate on-device AI systems. Neither sends your email data
off your Mac.

## How updates land

If you're on v0.1.7-alpha, **PrivateAIMail → Check for Updates…** installs
this update in place. On first launch, migration M009 runs once (a few
seconds) and your threads reappear under All Accounts / Inbox immediately.

## Post-update notes

- After install, optionally press `⌘R` for an incremental sync — this
  replaces M009's backfilled INBOX labels with the real label set from Gmail.
- The Translated tab re-runs translation against the new HTML-preserving
  pipeline. Cached translations from v0.1.7 are dropped.
- New keyboard shortcut: `⌘⇧R` opens the inline composer and drafts a
  reply for the active thread.
- Drag the splitters between sidebar / threadlist / reading / brief to
  resize. Toolbar icons toggle sidebar and brief collapse. Layout persists
  across quits.

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account whose email is listed under **Test users** of the
  app's OAuth consent screen (project `mediaplatform-210614`)

## Installation (fresh)

1. Download `PrivateAIMail-0.1.8-alpha.dmg`.
2. Mount the DMG and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper (one-time, this build is ad-hoc-signed):
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
4. First launch downloads the Gemma 4 E2B model (~3.6 GB).

## Known limitations

- App Sandbox disabled for alpha (will return with Developer ID
  notarization)
- Snooze requires a background scheduler — Phase 2
- Log to CRM requires an integration (Notion/HubSpot/Salesforce) — Phase 2
- Per-node translation cache is in-memory only; restarts re-translate
- Ad-hoc signed — see installation steps for the one-time Gatekeeper
  unblock
