PrivateAIMail 0.1.0-alpha

First alpha release of PrivateAIMail for macOS.

  • Gmail account connection via OAuth
  • Thread list with AI-generated briefs (on-device Gemma 4 E2B)
  • Reply composer with real Gmail send
  • Automatic updates via Sparkle

Known limitations: single-window, no push notifications, no attachment preview, no Microsoft 365 support yet.
