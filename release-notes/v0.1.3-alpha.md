# PrivateAIMail 0.1.3-alpha

## Fixed

- **Sparkle auto-update no longer fails with "An error occurred while
  launching the installer".** Earlier alpha builds were sandboxed
  (`com.apple.security.app-sandbox = true`) and opted into Sparkle's
  XPC helpers via `SUEnableInstallerLauncherService`. But the Swift
  Package Manager distribution of Sparkle we ship does not include
  `InstallerLauncher.xpc`, so the sandboxed app could never spawn the
  installer helper. Sparkle has been silently broken since v0.1.0-alpha
  — every upgrade so far has actually been a manual DMG install.
- App Sandbox is disabled for the alpha track. Hardened Runtime stays
  enabled (notarization-readiness preserved). Sandbox will return
  alongside the non-SPM Sparkle distribution + Developer ID signing
  once we move past alpha.

## How updates land

If you installed v0.1.2-alpha or earlier already, manually replace the
app this one time (Sparkle in those builds cannot perform the upgrade):

1. Download `PrivateAIMail-0.1.3-alpha.dmg` from this release.
2. Mount it, drag **PrivateAIMail** to `/Applications`, overwriting.
3. `xattr -d com.apple.quarantine /Applications/PrivateAIMail.app`
4. Launch.

From v0.1.3-alpha onward, Sparkle works normally — **PrivateAIMail →
Check for Updates…** will install the next release in-place.

## What's included (carried from 0.1.2-alpha)

- Gmail OAuth login (Swift 6 isolation crash fixed: `@Sendable [box]`
  + `SessionBox` so the `ASWebAuthenticationSession` completion no
  longer inherits `@MainActor` and the runtime check doesn't SIGTRAP)
- Thread list with on-device AI briefs (Gemma 4 E2B, ~3.6 GB
  first-launch download)
- Reply composer with real Gmail send
- Automatic updates via Sparkle 2 (now actually functional)

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account whose email is listed under **Test users** of the
  app's OAuth consent screen (project `mediaplatform-210614`)

## Installation (fresh)

1. Download `PrivateAIMail-0.1.3-alpha.dmg`.
2. Mount the DMG and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper (one-time, this build is ad-hoc-signed):

   **Terminal:**
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
   then double-click as usual.

   **GUI:** double-click → click Done on the warning → System Settings →
   Privacy & Security → scroll to the blocked-app row → Open Anyway.
4. First launch downloads the Gemma 4 E2B model (~3.6 GB).

## Known limitations

- Single-window interface only
- No push notifications (polling-based sync)
- No attachment preview
- No Microsoft 365 / Outlook support yet
- Ad-hoc signed — see installation steps for the one-time Gatekeeper
  unblock
- App Sandbox disabled for alpha; will be restored alongside Developer
  ID notarization
