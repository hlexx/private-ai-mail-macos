# PrivateAIMail 0.1.10-alpha

## Fixed

- **Archive emptied, Inbox flooded with archived mail.** The M008/M009
  migrations from v0.1.7/v0.1.8 backfilled the `INBOX` label for any
  thread that didn't carry an explicit `TRASH/SPAM/DRAFT` label.
  Archived threads in Gmail look identical to "should-be-inbox" from
  that local point of view, so the backfill flooded Inbox with every
  archived thread (490+ in user's account) and emptied Archive.

  Fix in two parts:
  1. New `LabelReconciler` class asks Gmail directly which threads
     are currently in `INBOX` (one paginated
     `users.messages.list?q=label:INBOX` per account), then rewrites
     local `thread_label.INBOX` rows to match.
  2. Migration M010 sets a one-shot flag `pam.needsLabelReconcile` —
     on first launch of v0.1.10 the app reads the flag, runs the
     reconciler in the background across every connected account,
     clears the flag, and shows a toast **"Refreshing labels from
     Gmail…"** while it runs.

  Other labels (`STARRED`, `SENT`, user-defined) are untouched. AI
  briefs in `thread_brief` survive (no re-summarisation triggered).
  After the reconcile finishes, Inbox / Archive / Starred / Sent all
  reflect Gmail's actual state.

## How updates land

If you're on **v0.1.8-alpha or v0.1.9-alpha**, **PrivateAIMail → Check
for Updates…** installs this fix in place. On first launch after
update you'll see the toast briefly while the reconciler queries
Gmail; it usually completes in 2–10 seconds per account on a
500-thread inbox. After it clears, the sidebar counts are accurate.

If your v0.1.8 was crashing on launch (NSSplitView issue, fixed in
v0.1.9), and v0.1.9 hadn't launched even once, you may need to
manually install v0.1.10 from this release page.

## What's included (carried from 0.1.9-alpha)

- Email-client keyboard shortcuts (Apple Mail + Gmail conventions)
- `?` keyboard-shortcut help overlay + Settings → Keyboard tab
- Focus-aware single-letter shortcuts
- NSSplitView delegate crash fix (v0.1.9)
- Persistent thread briefs, HTML rendering, real AI in composer,
  label-aware sync, mutations, translation, multi-language replies

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account in the OAuth Test users list

## Installation (fresh)

1. Download `PrivateAIMail-0.1.10-alpha.dmg`.
2. Mount, drag **PrivateAIMail** to `/Applications`.
3. ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
4. Launch. First-launch AI model download is ~3.6 GB.

## Known limitations

- Re-running label reconcile manually requires re-triggering the M010
  flag (currently no Settings button — will be added in a later
  release alongside per-account label refresh control).
- CID images requiring `messages.attachments.get` download are still
  Phase 2.
- App Sandbox off for alpha; back on with Developer ID notarisation.
- Ad-hoc signed.
