# Re:Box 0.1.15-alpha

## Fixed

- **Label refresh no longer fails on demo accounts.** The startup label
  reconciliation now skips accounts without saved Keychain credentials instead
  of treating them as failed Gmail accounts.

- **Clear reconnect state for expired Gmail credentials.** If Gmail rejects the
  saved token, Re:Box keeps the retry flag and shows a reconnect message instead
  of a generic retry-on-next-launch notice.

- **Correct toast severity.** Error notifications now use an error icon and
  error color instead of the green success checkmark.

## Validation

- Full `MacAppTests` suite passed.
- `DesignSystem` package tests passed.
- Debug macOS build passed.
