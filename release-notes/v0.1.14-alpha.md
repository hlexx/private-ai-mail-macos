# Re:Box 0.1.14-alpha

## Fixed

- **Startup database migration fix.** Re:Box now recognizes the previously
  shipped `M011_AttachmentDataPlane` migration instead of trying to create the
  same attachment tables again under a different migration name.

- **Attachment summary schema compatibility.** Attachment summary storage now
  works with the attachment data-plane schema already present in `0.1.12-alpha`
  user databases, while still adding the new local byte-store table needed by
  the PromptTask attachment summary path.

## Validation

- Existing databases with `M011_AttachmentDataPlane` migrate forward without
  recreating `attachment_extraction`, `attachment_chunk`, or
  `attachment_ai_artifact`.
- Fresh databases still receive the attachment data-plane tables and the local
  attachment byte-store table.
