# Re:Box 0.1.12-alpha

## New

- **Attachment intelligence in the reading pane.** Messages now show real
  attachment cards with local-file, extraction, processing, summary, evidence,
  unsupported-format, and missing-local-bytes states.

- **Re:Box app name.** The macOS display name, app menu, and Sparkle update
  prompt now use Re:Box.

- **Local attachment processing queue.** Attachment extraction and summary work
  now runs through a bounded local queue with cancellation, selected-attachment
  priority, duplicate-work protection, and explicit persistence of job state.

- **Local file preview.** Attachment preview opens the saved local file when it
  exists and reports a clear missing-file state when bytes have not been saved
  locally.

- **Manual privacy smoke test.** Project notes now include a manual verification
  path for PDF, text, unsupported, missing-local-file, and no-attachment
  messages, including log and network checks.

## Privacy and scope

- Attachment content stays on device.
- Extracted text, summaries, evidence chunks, and attachment bytes are not
  logged.
- This release does not add Gmail remote attachment download.
- This release does not add Team Connect, Slack, Notion, CRM, or cloud
  attachment processing.

## What's included (carried from 0.1.11-alpha)

- Mixed-language email translation with per-text-node language detection.
- Provider-backed inbox and archive mutation safety.
- Label reconciler for accurate Inbox and Archive state.
- Email-client keyboard shortcuts and shortcut help overlay.
- Persistent thread briefs, HTML rendering, real AI composer support, and
  label-aware sync.

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account in the OAuth Test users list

## Installation

1. Download `PrivateAIMail-0.1.12-alpha.dmg`.
2. Mount the DMG and drag **Re:Box** to `/Applications`.
3. If macOS blocks the first launch for the alpha build, run:
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
4. Launch the app. First-launch AI model download is ~3.6 GB.

## Known limitations

- Gmail attachment bytes must already be present locally; the app does not
  fetch missing attachment bytes from Gmail in this release.
- Unsupported attachment formats are shown explicitly and are not summarized.
- Team Connect actions remain out of scope for this release.
- App Sandbox is off for alpha; re-enable with Developer ID notarisation.
- Ad-hoc signed unless Developer ID release credentials are present locally.
