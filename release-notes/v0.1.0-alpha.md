# PrivateAIMail 0.1.0-alpha

First alpha release of Private AI Mail for macOS.

## What's included

- **Gmail account** connection via OAuth 2.0
- **Thread list** with AI-generated briefs powered by on-device Gemma 4 E2B (~3.6 GB model download on first launch)
- **Reply composer** with real Gmail send
- **Automatic updates** via Sparkle 2 (EdDSA-verified)
- **Check for Updates** menu item under the app menu

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model

## Installation

1. Download `PrivateAIMail-0.1.0-alpha.dmg` from this release.
2. Mount the DMG and drag **PrivateAIMail** to `/Applications`.
3. **Unblock Gatekeeper.** This build is ad-hoc-signed (no Apple Developer ID yet), so macOS will show "Apple could not verify PrivateAIMail is free of malware." Pick one path:

   **Terminal (one line):**
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
   then double-click the app as usual.

   **GUI:** double-click the app → click **Done** on the warning → open **System Settings → Privacy & Security** → scroll to the blocked-app row → click **Open Anyway**.

   On macOS 14 and older the legacy *right-click → Open* trick also worked. Apple removed it for quarantined ad-hoc apps in macOS 15 (Sequoia), so use one of the two paths above.
4. On first launch the app downloads the Gemma 4 E2B model (~3.6 GB) — takes a few minutes on a typical connection.

## Known limitations

- Single-window interface only
- No push notifications (polling-based sync)
- No attachment preview
- No Microsoft 365 / Outlook support yet
- Ad-hoc signed — see the installation steps above for the one-time Gatekeeper unblock
