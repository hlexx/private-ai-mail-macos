# PrivateAIMail 0.1.5-alpha

## New features

- **HTML email rendering.** Marketing emails, newsletters, and
  HTML-heavy messages now display their full layout instead of a
  plain-text snippet. Remote images are blocked by default; a
  per-message "Show images" toggle loads them on demand.
- **Real AI reply composer.** The inline composer generates drafts
  on-device via Gemma 4 E2B. Three tone options (Concise / Warm /
  Direct) produce distinct drafts; Regenerate creates a fresh
  alternative each click. "Edit in full" hands the draft to the
  full compose window.
- **Sidebar folder filtering.** Click Inbox, Starred, Sent, or
  Archive in the sidebar to filter the thread list by Gmail label.
  Click an account row to scope everything to that account.
- **Archive / Star / Trash mutations.** Archive and star from the
  thread header, swipe-right to archive, swipe-left to trash.
  Changes apply optimistically and sync to Gmail. 8-second undo
  toast on destructive actions.
- **On-device translation.** When Settings > Preferred language
  differs from the thread language, an Original/Translated toggle
  appears. Translation runs on-device via Apple Translation
  framework (macOS 15+), no network required.
- **Multi-language AI replies.** The composer auto-detects the
  thread language and drafts in the same language. An eyebrow shows
  "Drafted in RU" (or whichever language). Override via a dropdown.
- **Localization (RU + DE).** All UI strings use `String(localized:)`
  with Russian and German translations as a sanity check for the i18n
  pipeline.

## Settings additions

- General tab: Preferred language, Default reply tone, Auto-translate
  foreign threads toggle.

## Layout fixes

- Brief rail CTAs and inline composer buttons no longer split
  mid-word at narrow widths. Adaptive stacking and
  `minimumScaleFactor` keep labels readable down to 280pt.

## How to test

1. Sidebar folders: click Inbox, then Archive, then Sent, then
   Starred. Each shows a different subset of threads.
2. HTML rendering: open a marketing email with full HTML layout.
   Verify "Remote images blocked" pill appears.
3. AI brief: open a 5-paragraph email. Brief mentions actual content.
4. Composer: switch tone segments. Three different drafts appear.
   Hit Regenerate for a 4th.
5. Reply language: open a Russian thread. Eyebrow says "in RU".
   Draft is in Russian.
6. Archive: hit Archive on a thread. Verify it disappears from
   Inbox and is archived in mail.google.com.
7. Translation: Settings > General > Preferred language = English.
   Open a Russian thread. Toggle to Translated. Body shows English.
8. Layout: resize window to 1200pt width. Brief rail CTAs and
   composer buttons stay on one line.

## System requirements

- macOS 15.0 or later
- Apple Silicon (arm64)
- ~3.6 GB free disk space for the on-device AI model
- A Google account listed under Test users of the app's OAuth
  consent screen

## Installation

1. Download `PrivateAIMail-0.1.5-alpha.dmg`.
2. Mount and drag **PrivateAIMail** to `/Applications`.
3. Unblock Gatekeeper:
   ```sh
   xattr -d com.apple.quarantine /Applications/PrivateAIMail.app
   ```
4. First launch downloads the Gemma 4 E2B model (~3.6 GB) if not
   already cached from a previous version.

## Known limitations

- Single-window interface only
- No push notifications (polling-based sync)
- No Microsoft 365 / Outlook support yet
- Ad-hoc signed; see installation steps for the Gatekeeper unblock
- App Sandbox disabled for alpha
